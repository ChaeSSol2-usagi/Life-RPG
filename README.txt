시간의 정원 v1.2 · 두 사냥터 통합 PWA

index.html, sw.js, manifest.webmanifest, bgm.mp3, 두 아이콘 파일을 GitHub Pages 저장소 최상위에 업로드하세요.
기존 게임을 삭제하지 마세요. 업데이트 전에 JSON 기록 백업을 다운로드하세요.
구버전 저장을 읽을 때 흉노 기록은 현재 총 기록을 초기값으로 이관합니다. 옛날에 이미 소비한 아이템의 정확한 총 획득량은 알 수 없으므로 현재 보유량을 초기 업적 값으로 사용합니다.
신규 사냥터는 가칭 '설원의 땅 (Lv.60~80)'입니다. 새로운 사냥터는 Lv.60 이후 사냥을 종료한 상태에서 이동할 수 있습니다.
자동 사냥, 지역별 기록, 텍스트 인벤토리, 스킬 승격 및 BGM 오프라인 캐시를 포함합니다.
실제 PC/갤럭시탭 브라우저 통합 실행 테스트는 미완료입니다. 최초 업데이트 후 백업을 유지하며 확인하세요.
배포용 BGM의 저작권 및 업로드 권한은 사용자가 별도로 확인해야 합니다.

[v1.2.1] Lv.60 지역 이름: 높:얼어붙은평원; 지역별 BGM 재생 및 오프라인 캐시.
