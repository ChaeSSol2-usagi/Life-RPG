높:흉노2지 PWA v0.8

1. 폴더의 파일을 모두 GitHub Pages 또는 HTTPS 정적 호스팅에 업로드합니다.
2. Chrome에서 https://주소/index.html 을 엽니다.
3. 갤럭시탭 Chrome 메뉴(⋮) > 홈 화면에 추가 > 설치 또는 앱 설치.
4. PC에서도 Chrome 주소창의 설치 버튼(또는 메뉴 > 앱 설치)으로 설치 가능합니다.
5. 처음 온라인으로 열어야 오프라인 캐시가 설치됩니다.
6. 파일을 더블클릭하여 여는 file:// 방식은 PWA 설치/서비스워커를 지원하지 않습니다.
7. 기존 v0.6과 같은 저장키를 사용하지만, HTTPS 사이트와 file://는 저장 영역이 달라 자동으로 데이터를 이전할 수 없습니다.
8. PWA에서 생성한 백업 JSON을 다른 기기에서 '기록 복원'으로 가져오세요.
9. 브라우저는 자동 재생 효과음을 제한할 수 있으므로 사냥 시작을 눌러 사운드를 활성화합니다.
10. 이 버전은 앱 설치 파일 모음입니다. 웹 호스팅 자체는 포함되지 않았습니다.

변경: 앱 이름 시간의 정원 / 태블릿 가로화면 전체 98% / 캐시 버전 갱신

[v0.9] 상단 제목: 시간의 정원 🌳. 일반 몬스터 솔 에르다 조각 0.08%; 선우 80% 1개 / 20% 2개. 기존 저장 데이터 유지.
